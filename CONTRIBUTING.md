# Contributing

This repository is a **personal BA study pack**. Contributions are welcome if they improve clarity, fix errors, or add practice artifacts that follow the same ethics.

## Before you change anything

1. Read [README.md](README.md) and, for healthcare, [18-Health-Domain-Research/00-how-to-use-this-pack.md](18-Health-Domain-Research/00-how-to-use-this-pack.md).
2. Keep **folder and file numbers**. Sequence is the syllabus.
3. Teaching companies stay fictional (ShopEase, NovaBank, MediCare+, ApexCare, HelixLab, CityWell, Nimbus Digital).
4. Label volumes and KPIs **illustrative** unless you cite a public source.
5. Do not add real client BRDs, HIS screenshots with patients, or any Personal Health Information (PHI) / Personally Identifiable Information (PII).

## What to contribute

| Welcome | Not welcome |
|---|---|
| Typo and expansion fixes (short name → full name) | Confidential templates from a workplace |
| Clearer As-Is / To-Be in a *practice* case | Claiming a real employer delivered this pack |
| Extra UAT scenarios on teaching companies | Live UHID, phones, claim IDs, discharge PDFs |
| Links to public regulators (RBI, IRDAI, NHA) | Scraped patient or staff data |

## How to propose a change

1. Fork or branch from `main`.
2. One concern per pull request (typos in file 02, or one new UAT table — not both mixed with a rewrite).
3. Fill in the pull request template.
4. Do not commit `.env`, keys, or Office lock files (`~$*`).

## Style

- Match existing notes: short sections, tables, **Weak vs strong**, Notes at the end.
- First mention of an abbreviation: `Hospital Information System (HIS)`.
- Healthcare Gen AI: Human-in-the-Loop (HITL); the model is not the author of the record.

## Questions

Open a GitHub Issue using the question template. Do not paste client documents into the issue.
