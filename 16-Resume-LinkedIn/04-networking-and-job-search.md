# Networking and Job Search

## Definition

**LinkedIn networking**, **recruiter visibility**, **job alerts**, and public **portfolio / GitHub** links used as a system — not random connection spam.

## Why it matters

Many BA seats never look like “easy apply.” A short, specific message plus a case link beats 200 empty connects. Tracking stops you from ghosting your own pipeline.

## Recruiter visibility

- Headline + Open to Work (recruiters-only if needed).
- Location and “Open to” titles: Business Analyst, Associate BA, Junior BA, IT BA — not 15 unrelated titles.
- Featured portfolio so a sourcer has somewhere to click.
- Activity: comment on a BA’s process post with a real question, not “Great share!”

## Job alerts

Set alerts on LinkedIn/Naukri/company pages: `"Business Analyst" intern/associate/fresher` + city + remote. Review 3 times a week. Tailor 2–4 applications deeply rather than 40 identical ATS dumps.

## Portfolio and GitHub profile

- LinkedIn Featured + resume header + email signature: one URL.
- GitHub profile README: who you are, two cases, how to contact. Pin the two case repos.
- Keep GitHub green by real commits to cases, not empty daily noise.

## How to message a BA or recruiter (not cringe)

**To a BA in the team (after they accept connect):**

```text
Hi Priya — I read your post on UAT with operations. I just finished a practice
case on marketplace returns (process + stories + a small SQL insight). If you
have 10 minutes in the next two weeks, I would value one piece of feedback on
whether my problem statement is sharp enough. Link: [GitHub]. No worries if not.
```

**To a recruiter on a live role:**

```text
Hi Amit — applying for Associate BA (Req 1842). I am a fresher with portfolio
work in e-commerce returns and loan origination (requirements + SQL, not
employment). Resume attached; 2-page case: [link]. Happy to walk through it.
```

**Do not:** “Dear Sir/Madam, I am a passionate go-getter. Please refer me. Regards, [name] sent from my iPhone.” Do not paste the whole resume in the note.

## Open to work vs spam

| OK | Spam |
|---|---|
| 8–10 targeted connects a week with a note | 50 connects a day, blank |
| Follow-up once after 7–10 days | Three follow-ups in 48 hours |
| Open to Work + real titles | “Open to Work” plus crypto influencer banner |
| Ask for *one* artifact critique | Ask for a job in sentence one to a stranger BA |

## Tracking applications

Spreadsheet columns: Date, Company, Role, Link, JD keywords used, Resume version, Contact, Status (applied / screen / case / reject), Next action, Notes.

Review Fridays: follow-ups, alert hygiene, which case to mention for which JD (ShopEase for retail, NovaBank for banking, MediCare+ for healthcare).

### Weak vs strong

| Weak | Strong |
|---|---|
| “Any openings in your company?” | Named role + one matching case |
| No tracker; apply twice | Spreadsheet prevents duplicate and ghosting |
| GitHub empty, LinkedIn busy | Both point to the same two cases |

## Real-world examples

1. You message a NovaBank BA about loan TAT; they skip HR and forward your case — rare but real when the case is specific.
2. You mass-connect 200 recruiters; LinkedIn restricts you; visibility drops.
3. Alert fires on MediCare+ vendor; you already have the reminder case — apply same day with a tailored summary.

## Scenario / Use case: two weeks of a disciplined search

**Context.** You want an Associate BA role in Pune. You have ShopEase + NovaBank cases live.

**Week plan.**

1. Alerts on; tracker created.
2. 6 tailored applications (keywords mapped).
3. 8 connection notes (4 BAs, 4 recruiters) using templates above.
4. One comment on a process-mapping post that quotes *your* seller-approval finding (no client secrets).
5. Friday: two follow-ups, one GitHub typo fix.

**What goes wrong if ignored.** “Easy apply” 40 times, zero notes, dead GitHub. Networking feels icky because the messages were generic. Specific + sparse beats loud.

## Notes

- Visibility = headline, titles, Featured, not spam.
- Messages name the person, the case, and a small ask.
- Alerts + tracker + matching case to JD is the job-search process.
- Portfolio and GitHub must be the same story as the resume.
- Open to Work is a setting; it is not a substitute for applications.
