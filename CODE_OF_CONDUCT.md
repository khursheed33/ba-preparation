# Code of Conduct

This is a learning repository. Be precise, respectful, and careful with other people’s data.

## Expected

- Critique ideas and documents, not people.
- Flag confidential or health data immediately; do not reshare it.
- Label practice metrics **illustrative**.
- Do not impersonate work at a real hospital, bank, or insurer.

## Not acceptable

- Harassment or discriminatory comments
- Pasting Personal Health Information (PHI) or secrets into issues or pull requests
- Scraping or doxxing

## Enforcement

The repository maintainers may edit or close contributions that break these rules. For a data incident, see [SECURITY.md](SECURITY.md).
