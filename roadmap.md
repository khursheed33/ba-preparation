# 🗺️ Complete Business Analyst Roadmap

The roadmap below is intentionally **topic-focused rather than lesson-focused**. She can use it as a syllabus/research map and independently learn each topic. I’ve also included some areas that are commonly expected in current BA roles, such as SQL, Excel, process modeling, Agile, Jira/Confluence, BI, UAT, and AI literacy. ([Scaler][1])

**Competency map** (job-ad language) → **study sequence** (folders `01`–`18`). Do not renumber folders to match the 13 competencies; sequence is the syllabus.

| Competency | Primary folders |
|---|---|
| 1. BA fundamentals (role, BABOK, lifecycle, types) | `01` |
| 2. Requirements engineering | `02`, `03` |
| 3. Stakeholder management | `01` (stakeholders, RACI, comms plan), `02` |
| 4. Business process management | `04` (incl. Lean / Six Sigma, BPMN) |
| 5. Analysis techniques | `12`, `04` |
| 6. Solution assessment & design | `03` (FRD), `04` (DFD, ERD, UML), `06` (wireframes) |
| 7. Project & delivery methodologies | `01` (SDLC), `05` |
| 8. Documentation & tools | `03`, `06`, `07`, `08` |
| 9. Data analysis basics | `07`, `08`, `09` |
| 10. Testing & UAT | `10` |
| 11. Domain knowledge | `11`, `18` |
| 12. Soft skills | `01` (communication, facilitation), `02` (negotiation) |
| 13. Business & financial acumen | `12` (business case, org, change), CBA in `12` |

Extra preparation (not in the 13): AI `14`, portfolio `15`, resume `16`, interviews `17`, healthcare pack `18`.
